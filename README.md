
# 🗂️ Auto File Organizer

**Auto File Organizer** یک ابزار ساده و کاربردی نوشته‌شده با پایتون است که پوشه‌ها را به‌صورت خودکار مرتب می‌کند.  
فایل‌ها بر اساس نوعشان (عکس، ویدیو، سند، موسیقی، کد و...) در پوشه‌های جداگانه قرار می‌گیرند.

## 🚀 ویژگی‌ها
- مرتب‌سازی خودکار فایل‌ها بر اساس پسوند
- پشتیبانی از چندین نوع فایل (عکس، سند، ویدیو، موسیقی، کد، آرشیو)
- انتقال فایل‌های ناشناخته به پوشه‌ی `Others`

## ⚙️ نحوه اجرا
1. این پروژه را دانلود کنید
2. برنامه را اجرا کنید:
   ```bash
   python3 file_organizer.py
   ```
3. مسیر پوشه‌ای که می‌خواهید مرتب شود را وارد کنید.
4. فایل‌ها به‌صورت خودکار در پوشه‌های جداگانه قرار می‌گیرند 🎉
